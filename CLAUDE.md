# Установка метода KOROBEINIKOV AI — инструкция для Claude

Выполняй её, только если человек сам просит поставить метод. Просто смотрит репозиторий — ничего не запускай.

Перед тобой предприниматель, не программист. Возможно, он первый раз в Терминале.
- Пиши по-русски, коротко и просто, по одному шагу за раз. Без терминов и названий команд.
- Команды выполняй сам, человеку их не показывай. От него — только руки: каждый раз скажи точно, что нажать
  и что должно получиться.
- Скачивать этот репозиторий не нужно. Homebrew не ставь. Кроме шагов ниже ничего не делай: остальное
  сделает проводник пакета после перезапуска.

## Шаг 1. Проверь, что это Mac
Команда `uname` ответила не `Darwin` — скажи честно, что пока метод работает только на Mac, и на этом закончи.

## Шаг 2. Инструменты Apple
Без них ничего не поставится. Выполни `xcode-select -p`.
- Ответил путём — они уже есть, иди дальше.
- Нет — запусти `xcode-select --install`, сразу напиши человеку текст ниже и остановись: не жди сам и больше
  ничего не запускай, пока он не ответит. «На экране появилось окно: нажмите „Установить“ и примите условия.
  Дальше скачивается само, обычно до получаса. Когда окно сообщит, что всё установлено, напишите мне „готово“».
  Ответил — снова `xcode-select -p`. Ответил путём — иди дальше, нет — попроси подождать ещё.

## Шаг 3. Пакет
Выполни по очереди:
```
claude plugin marketplace add korobeinikov-ai/method
claude plugin install osnova@korobeinikov-ai-method
```
Ответ «уже стоит» — это не ошибка, иди дальше.

## Шаг 4. Передай проводнику
Скажи: метод поставлен, остался один перезапуск. Наберите `/exit`, нажмите Enter, потом наберите
`claude начнём` и снова нажмите Enter. Дальше всё объяснит проводник.

## Если что-то не вышло
Прочитай ошибку и почини сам. Не вышло с двух попыток — скажи простыми словами, что случилось, и посоветуй
написать автору там, где вы с ним общаетесь.
