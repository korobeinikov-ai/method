# Маршрут «свой компьютер»

Самый мягкий вход: всё на компьютере человека, кроме Claude Code и GitHub ничего не нужно. Результат —
вещь, которую можно запускать снова каждую неделю, а не разовый ответ в чате.

## 1. Понять задачу
Вопросы по одному, с вариантами ответа:
- Что на входе: какие файлы, откуда приходят, как часто (каждую неделю новый Excel?). Google-таблица →
  человек скачивает её: «Файл → Скачать → Microsoft Excel».
- Что должно получиться: таблица, сводка, документ; что в нём главное (итоги по товарам? по дням?).
- По какой цифре человек проверит результат — что он знает наверняка (итог за прошлый месяц и т.п.).

Сформулируй «Готово = …» одной фразой и покажи человеку.

## 2. Завести часть проекта
Своя папка части внутри проекта (например, `otchet-prodazhi/`):
- `vhod/` — сюда человек кладёт исходные файлы, `vyhod/` — сюда ложится результат. Обе папки — в
  `.gitignore` части: файлы с данными бизнеса не уходят в git и на GitHub, в истории — только обработка.
  Скажи человеку об этом одной строкой.
- Открой папку человеку (`open vhod`) и скажи: «перетащите сюда файл и напишите „положил“».
- `STRUCTURE.md` части: что делает, что на входе, что на выходе, как запустить. Строку о части — в карту
  проекта.

## 3. Сделать
- Сначала посмотри на настоящий файл: листы, заголовки, первые строки. Кривые заголовки, объединённые
  ячейки, пустые строки — обычное дело; обработку пиши под то, что увидел.
- Python с отдельной средой в папке части: `python3 -m venv .venv`, библиотеки — `.venv/bin/pip install …`
  (Excel — openpyxl или pandas, Word — python-docx, PDF — pdfplumber), список — в `requirements.txt`.
- Исходные файлы человека только читай; результат — новым файлом в `vyhod/`.
- Excel на выходе — для человека: понятные заголовки по-русски, ширина колонок, итоги. Где человек
  посчитал бы формулой — ставь формулу, чтобы было видно, откуда цифра.

## 4. Доказать
- Запусти на настоящем файле и открой результат человеку (`open vyhod/<файл>`).
- Сверь с цифрой, которую назвал человек на шаге 1. Совпало — так и скажи. Не совпало — сначала найди
  причину, не подгоняй.
- Судья — как после любой законченной работы.

## 5. Чтобы запускать снова без Claude
Задача повторяется → сделай в папке части файл `Обновить.command` (и `chmod +x`):

```bash
#!/bin/bash
cd "$(dirname "$0")" && .venv/bin/python obrabotka.py && open vyhod
```

Скажи человеку: «Кладёте новый файл в vhod и дважды щёлкаете „Обновить“ — результат откроется сам».
Проверь двойной щелчок вместе с человеком один раз.

## Когда маршрут кончается
Нужен результат в Telegram или чтобы работало без компьютера (по расписанию, по кнопке, для сотрудников) —
это навык `telegram-bot`: обработка из этой части переезжает в бота почти без изменений. Нужен сайт — скажи, что
этот маршрут готовится.
