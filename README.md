# Метод KOROBEINIKOV AI

Метод для предпринимателей: Claude ведёт вас от «хочу» до работающей вещи и сам делает всю технику.
Вы думаете о деле и процессах, а от вас нужны только руки: подтвердить вход и нажать кнопку там,
где Claude скажет.

## Что нужно
Mac с macOS 13 или новее (или компьютер с Windows 10 версии 1809 и новее либо Windows 11) и платная подписка Claude
(Pro или выше). И доступ к опыту автора: нажмите
«Хочу доступ» в боте метода https://t.me/korobeinikov_aibot. Когда автор откроет доступ, бот пришлёт личный текст
для установки: вставьте его в шаге 3 вместо общего. Он поставит то же самое и сразу подключит доступ. Без доступа
пакет ставится и работает, но опыта автора в нём не будет. На новом компьютере установка обычно занимает до получаса,
почти всё это время идёт скачивание.

## Как поставить

**1. Поставьте приложение Claude.** Скачайте его со страницы https://claude.ai/download, откройте скачанный файл
и перетащите Claude в папку «Программы» (на Windows — пройдите установку, Claude появится в «Пуске»). Запустите
Claude и войдите своей подпиской.

**2. Откройте раздел Code.** Переключатель разделов — вверху окна. Под полем ввода выберите папку для работы:
подойдёт «Документы». Папку для ваших проектов Claude потом заведёт сам.

**3. Вставьте в поле ввода текст и нажмите Enter:**

```
Установи метод Коробейникова. Прочитай инструкцию для тебя целиком и сделай всё по ней: https://raw.githubusercontent.com/korobeinikov-ai/method/main/CLAUDE.md
```

Есть личный текст из бота — вставьте его вместо этого.

Дальше всё делает Claude: он сам видит, Mac у вас или Windows. От вас — пара кнопок и два ответа:
- Claude спрашивает разрешение — нажмите «Разрешить».
- На Mac появится окно Apple — нажмите «Установить» и примите условия. Windows может спросить «Разрешить этому
  приложению вносить изменения?» — нажмите «Да».
- Пока идёт скачивание, Claude спросит, как называется ваше дело, а потом — можно ли поставить настройки как у автора.
- В конце нажмите кнопку под сообщением Claude: откроется ваш проект, и можно начинать работу.

Несколько минут может ничего не происходить, это нормально: идёт скачивание.

**Уже ставили метод раньше через Терминал?** Переставлять ничего не нужно: приложение видит тот же метод. В разделе
Code выберите папку своего проекта (она лежит в папке vibecoding в вашей домашней папке) и работайте как обычно.

## Что пакет делает на компьютере
Ставит инструменты Apple через окно Apple (на Windows — Git и Python) и три небольшие программы: связь с GitHub,
сканер секретов, проверку кода. Заводит папку vibecoding в домашней папке: там живут ваши проекты.
Следит, чтобы ключи и пароли не попали в сохранения. Обновляется сам: новая версия скачивается в начале работы
и начинает действовать в следующем сеансе Claude. Настройки Claude меняет только с вашего «да». Опыт автора забирает
с сервера метода по вашему личному ключу: ключ лежит в закрытом файле на компьютере, сервер помнит только, какой
навык и когда вы взяли. В личном тексте из бота не ключ, а одноразовая ссылка: она срабатывает один раз и сама кладёт
ключ в этот файл, мимо разговора. Ваши файлы и разговоры автору не отправляет.

Версия для Windows живёт отдельно, в https://github.com/korobeinikov-ai/method-windows: опыт автора там тот же, а установка
и охрана обновляются реже.

## Вопросы и ошибки
Пишите автору там, где вы с ним общаетесь. Пакет даётся как есть: за свой проект отвечаете вы.
