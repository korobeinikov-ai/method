# Метод KOROBEINIKOV AI

Метод для предпринимателей: Claude ведёт вас от «хочу» до работающей вещи и сам делает всю технику.
Вы думаете о деле и процессах, а от вас нужны только руки: подтвердить вход и нажать кнопку там,
где Claude скажет.

## Что нужно
Mac с macOS 13 или новее и платная подписка Claude (Pro или выше). На новом Mac установка обычно занимает до получаса,
почти всё это время идёт скачивание.

## Как поставить

**1. Откройте Терминал.** Нажмите Cmd+Пробел, наберите «Терминал» (или Terminal) и нажмите Enter. Поиск не
открылся — зайдите в Finder → Программы → Утилиты → Терминал. Откроется окно для команд.

**2. Вставьте в него строку и нажмите Enter:**

```
bash <(curl -fsSL https://raw.githubusercontent.com/korobeinikov-ai/method/main/install.sh)
```

Она поставит всё нужное: инструменты Apple, Claude и Zed (программу, в которой вы будете работать с Claude
и видеть файлы проекта). Что уже стоит, она не тронет. Появится окно Apple — нажмите «Установить» и примите
условия. Если Mac спросит пароль, введите пароль от компьютера: символы на экране не появляются, это нормально.
Несколько минут экран может молчать, это нормально: идёт скачивание.

Ход установки видно по значкам: ✅ готово, ⏳ идёт, ⚠️ не страшно, ❌ не вышло. Рядом с ❌ написано, что делать и как
запустить снова. Появилось только `curl:` и текст на английском — строка не смогла скачаться: проверьте интернет
и вставьте её ещё раз.

**3. Войдите.** Запустится Claude. На первых вопросах нажимайте Enter, потом откроется браузер: войдите
своей подпиской.

**На вопросе про папку будьте внимательны.** Claude спросит, доверяете ли вы папке, и по умолчанию там стоит «нет»
(`No, exit`). Нажмите стрелку вниз, чтобы выбрать `Yes, I trust this folder`, и только потом Enter. Промахнулись и Claude
закрылся — установка скажет, как запустить её снова.

Дальше Claude проведёт сам. Он будет спрашивать разрешение перед каждым действием: просто нажимайте Enter.

**Если Claude открылся, но сам не начал,** вставьте в поле для ввода текст ниже и нажмите Enter.
Если в поле уже есть серая строка, это только подсказка: вставляйте поверх, Enter на ней не нажимайте.

```
Установи систему метода Коробейникова. Прочитай инструкцию для тебя целиком и сделай всё по ней: https://raw.githubusercontent.com/korobeinikov-ai/method/main/CLAUDE.md
```

## Что пакет делает на компьютере
Строка установки подсказывает Mac, где лежит Claude, а новому Zed — сразу показывать окно для команд.
Сам пакет ставит три небольшие программы (связь с GitHub, сканер секретов, проверка кода). Следит, чтобы ключи и пароли не попали в сохранения. Обновляется сам: новая версия скачивается в начале работы и начинает действовать
при следующем запуске Claude. Настройки Claude меняет только с вашего «да». Ваши файлы автору не отправляет.

## Вопросы и ошибки
Пишите автору там, где вы с ним общаетесь. Пакет даётся как есть: за свой проект отвечаете вы.
