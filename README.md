# Метод KOROBEINIKOV AI

Метод для предпринимателей: Claude ведёт вас от «хочу» до работающей вещи и сам делает всю технику.
Вы думаете о деле и процессах, а от вас нужны только руки: подтвердить вход и нажать кнопку там, где Claude скажет.

Сайт: https://korobeinikov.ai

## Для кого
Для предпринимателей, которые не программируют: хватит уровня ChatGPT и Excel. Нужны Mac с macOS 13 или новее
(или компьютер с Windows 10 версии 1809 и новее либо Windows 11) и платная подписка Claude (Pro или выше).

## Как поставить
1. **Поставьте приложение Claude** со страницы https://claude.ai/download и войдите своей подпиской.
2. **Откройте раздел Code** (переключатель вверху окна). Под полем ввода выберите папку «Документы».
3. **Вставьте в поле ввода фразу для своего компьютера и нажмите Enter.**

Mac:
```
Установи метод Коробейникова. Прочитай инструкцию для тебя целиком и сделай всё по ней: https://raw.githubusercontent.com/korobeinikov-ai/method/main/CLAUDE.md
```

Windows:
```
Установи метод Коробейникова. Прочитай инструкцию для тебя целиком и сделай всё по ней: https://raw.githubusercontent.com/korobeinikov-ai/method-windows/main/CLAUDE.md
```

Дальше всё делает Claude. От вас — пара кнопок и два ответа:
- Claude спрашивает разрешение — нажмите «Разрешить».
- На Mac появится окно Apple — нажмите «Установить», потом «Принимаю». Кнопку про Xcode не нажимайте. Windows может
  спросить «Разрешить этому приложению вносить изменения?» — нажмите «Да».
- Claude спросит, как называется ваше дело, и можно ли поставить настройки как у автора.
- В конце нажмите кнопку под сообщением Claude: откроется ваш проект, и можно начинать работу.

Установка обычно занимает до получаса, почти всё это время идёт скачивание.

Уже ставили метод раньше? Переставлять ничего не нужно: метод обновится сам. В разделе Code откройте папку своего
проекта (она лежит в папке vibecoding в вашей домашней папке) и работайте как обычно.

## Что внутри
- Правила работы: Claude говорит просто, делает технику сам и ведёт одним проверенным путём.
- Охрана: ключи и пароли не попадают в сохранения, «готово» — только после проверки, судья смотрит на готовую работу.
- Опыт автора: свой компьютер (таблицы и файлы), Telegram-бот, выкладка в интернет, база данных, таргетолог для рекламы
  в Instagram и Facebook, цифровая безопасность, поиск причины поломки, разбор рисков перед большим делом.

Всё это лежит в самом пакете, обновляется само и начинает действовать в следующем сеансе Claude. Настройки Claude
пакет меняет только с вашего «да». Ваши файлы и разговоры никуда не отправляет.

## Вопросы
Пакет даётся как есть: за свой проект отвечаете вы. Пишите автору там, где вы с ним общаетесь.
