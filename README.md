# Метод KOROBEINIKOV AI

Метод для предпринимателей: Claude ведёт вас от «хочу» до работающей вещи и сам делает всю технику.
Вы думаете о деле и процессах, а от вас нужны только руки: подтвердить вход и нажать кнопку там,
где Claude скажет.

## Что нужно
Mac и платная подписка Claude (Pro или выше). На новом Mac установка обычно занимает до получаса,
почти всё это время идёт скачивание. Если Claude уже стоит, шаг 3 пропустите.

## Как поставить

**1. Поставьте Zed.** Это программа, в которой вы будете работать с Claude и видеть файлы проекта. Скачайте её:
[для Mac на чипе Apple (M1 и новее)](https://cloud.zed.dev/releases/stable/latest/download?asset=zed&os=macos&arch=aarch64)
или [для Mac на Intel](https://cloud.zed.dev/releases/stable/latest/download?asset=zed&os=macos&arch=x86_64).
Какой у вас, видно так: яблоко в левом верхнем углу → «Об этом Mac». Откройте скачанный файл, перетащите Zed
в «Программы» и запустите его оттуда. Mac спросит, открывать ли, — нажмите «Открыть». Аккаунт Zed не нужен.

**2. Откройте терминал в Zed.** В верхнем меню нажмите View → Terminal Panel. Внизу появится окно для команд.

**3. Поставьте Claude.** Вставьте в это окно строку и нажмите Enter:

```
curl -fsSL https://claude.ai/install.sh | bash
```

Несколько минут экран будет молчать, это нормально: идёт скачивание. Ждите надпись `Installation complete`.

**4. Войдите.** Наберите `claude`, нажмите Enter и войдите своей подпиской (откроется браузер).
Если в ответ появится `command not found`, вставьте эту строку, нажмите Enter и наберите `claude` снова:

```
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```

**5. Вставьте фразу.** Когда появится поле для ввода, вставьте в него текст ниже и нажмите Enter.
Если в поле уже есть серая строка, это только подсказка: вставляйте поверх, Enter на ней не нажимайте.

```
Установи систему метода Коробейникова. Прочитай инструкцию для тебя целиком и сделай всё по ней: https://raw.githubusercontent.com/korobeinikov-ai/method/main/CLAUDE.md
```

Claude будет спрашивать разрешение перед каждым действием: просто нажимайте Enter.

Дальше Claude проведёт сам.

## Что пакет делает на компьютере
Ставит три небольшие программы (связь с GitHub, сканер секретов, проверка кода). Следит, чтобы ключи и пароли не попали в сохранения. Обновляется сам: новая версия скачивается в начале работы и начинает действовать
при следующем запуске Claude. Настройки Claude меняет только с вашего «да». Ваши файлы автору не отправляет.

## Вопросы и ошибки
Пишите автору там, где вы с ним общаетесь. Пакет даётся как есть: за свой проект отвечаете вы.
