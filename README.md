# Метод KOROBEINIKOV AI

Метод для предпринимателей: Claude ведёт вас от «хочу» до работающей вещи и сам делает всю технику.
Вы думаете о деле и процессах, а от вас нужны только руки: подтвердить вход и нажать кнопку там,
где Claude скажет.

## Что нужно
Mac и платная подписка Claude (Pro или выше). На новом Mac установка обычно занимает до получаса,
почти всё это время идёт скачивание. Если Claude уже стоит, сразу переходите к шагу 3.

## Как поставить

**1. Поставьте Claude.** Откройте Терминал: ⌘ + пробел, наберите «Терминал», Enter. Вставьте строку и нажмите Enter:

```
curl -fsSL https://claude.ai/install.sh | bash
```

Несколько минут экран будет молчать, это нормально: идёт скачивание. Ждите надпись `Installation complete`.

**2. Войдите.** Наберите `claude`, нажмите Enter и войдите своей подпиской (откроется браузер).
Если Терминал ответит `command not found`, вставьте эту строку, нажмите Enter и наберите `claude` снова:

```
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```

**3. Вставьте фразу.** Когда появится поле для ввода, вставьте в него текст ниже и нажмите Enter.
Если в поле уже есть серая строка, это только подсказка: вставляйте поверх, Enter на ней не нажимайте.

```
Поставь мне пакет KOROBEINIKOV AI. Я не программист: всё делай сам, пиши коротко, а где нужны мои руки — скажи точно, что нажать. Homebrew не ставь. По шагам:
1) Проверь xcode-select -p. Инструментов Apple нет — запусти xcode-select --install, скажи мне в окне нажать «Установить» и дождись конца в фоне.
2) Выполни claude plugin marketplace add korobeinikov-ai/method, затем claude plugin install osnova@korobeinikov-ai-method.
3) Скажи мне набрать /exit, а потом claude начнём.
```

Дальше Claude проведёт сам.

## Что пакет делает на компьютере
Ставит три небольшие программы (связь с GitHub, сканер секретов, проверка кода) и следит, чтобы ключи и пароли
не попали в сохранения. Обновляется сам: новая версия скачивается в начале работы и начинает действовать
при следующем запуске Claude. Настройки Claude меняет только с вашего «да». Ваши файлы автору не отправляет.

## Вопросы и ошибки
Пишите автору там, где вы с ним общаетесь. Пакет даётся как есть: за свой проект отвечаете вы.
